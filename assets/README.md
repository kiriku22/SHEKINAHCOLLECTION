# Assets de Shekinah Collection

Esta carpeta contiene los espacios reservados para las 29 imagenes de producto y el logo.

- `logo-placeholder.svg`: reemplazalo por el logo final conservando este nombre, o actualiza la ruta en `index.html`.
- `product-01.svg` a `product-29.svg`: reemplaza cada archivo por la fotografia correspondiente, conservando los nombres para que el catalogo las encuentre automaticamente.

Recomendacion: usa imagenes cuadradas, minimo 900 x 900 px, en JPG o WebP. Si cambias la extension, actualiza las rutas en `script.js`.

El numero de WhatsApp de ejemplo esta en `index.html` y debe reemplazarse en los dos enlaces `https://wa.me/...`.
